# Codex Gig Workspace

This is the Codex-oriented recreation of the reviewed Chotaku Gig packet:

`I will build custom Python AI automation and workflow tools`

It is intentionally separate from the seller-facing draft at
`gigs/chotaku-build-custom-python-ai-automation-and-workflow-tools/` so Codex
can iterate on copy, acceptance criteria, and local preflight without
overwriting the original packet.

## Local-only boundary

- No Fiverr login, browser automation, scraping, tunnel, API credential, or
  publishing action is included.
- `gig.json` is a draft representation, not an instruction to edit Fiverr.
- Claims and portfolio proof require human evidence review before publication.
- Buyer examples must be fictional or redacted; never store passwords, cookies,
  API keys, tokens, or private client material here.

## Codex workflow

1. Read `gig.json` and `review-checklist.md`.
2. Run the local Seller OS Gig preflight against the draft.
3. Attach only approved evidence-card IDs to portfolio claims.
4. Review the diff and package feasibility manually.
5. Copy fields into Fiverr only after explicit human approval.
