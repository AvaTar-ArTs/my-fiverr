# Human Review Checklist

- [ ] Confirm title and category still match Fiverr's current form and rules.
- [ ] Confirm every package scope is deliverable within its stated window.
- [ ] Confirm the buyer requirements are clear and do not request credentials.
- [ ] Review every portfolio asset for ownership, permission, and client-data removal.
- [ ] Convert approved assets into Seller OS evidence cards.
- [ ] Run Gig preflight again after any copy or package edit.
- [ ] Check for guarantees, unsupported credentials, contact details, payment
      instructions, or claims about outcomes that have no approved evidence.
- [ ] Human explicitly approves the final copy before any Fiverr-side edit.

Publication remains a manual Fiverr action. The Seller OS does not log in,
click Save, or publish this draft.
