## Draft strategy

The draft keeps the current price ladder but narrows the promise to defined
workflows, documented interfaces, source code, and handoff documentation. It
avoids guarantees, unverifiable years-of-experience claims, off-platform
contact, and unsupported performance or revenue claims.

The first buyer conversation should qualify four facts:

1. desired outcome;
2. current process;
3. inputs and interfaces;
4. expected output.
