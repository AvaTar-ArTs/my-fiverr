# Fiverr Seller OS v3 Studio

V3 is an evidence-led studio increment built on the existing `local/` Seller
OS runtime. It is not a second application, database, MCP server, or tunnel.

The canonical path remains:

```text
/Users/steven/fiverr/local/
```

V3 adds source-linked evidence, Gig readiness packets, brief-response drafts,
deterministic policy preflight, and safe Markdown/CSV handoffs. Fiverr actions
remain manual and outside the runtime.

See the [research constraints](../docs/research/2026-08-12-seller-os-v3-official-constraints.md)
and [implementation plan](../docs/plans/2026-08-12-fiverr-seller-os-v3-implementation.md).
